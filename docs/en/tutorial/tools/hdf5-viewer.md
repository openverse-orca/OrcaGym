# 📊 HDF5 Viewer

This tool is used to view datasets collected from OrcaManipulation.

```python
from orca_gym.tools.hdf5_viewer import hdf5Viewer
```

## Usage

```bash
# Launch the HDF5 dataset viewer
python -m orca_gym.tools.hdf5_viewer.hdf5Viewer
```

The HDF5 viewer is used to visualize:

- Robot joint trajectories
- Camera image sequences
- Sensor data curves
- End-effector pose trajectories
