# 🔧 Tools & Adapters

OrcaGym provides a rich set of tools and adapters for mainstream RL/IL frameworks.

## Tools

| Tool | Location | Description |
|------|----------|-------------|
| Terrain Generation | `tools/terrains/` | Generate heightmap terrains |
| Asset Processing | `tools/assets/` | USDZ→XML, texture processing |
| HDF5 Viewer | `tools/hdf5_viewer/` | Dataset visualization |
| Install Helpers | `tools/install_helpers/` | Project download and configuration |

## Adapters

| Adapter | Location | Description |
|---------|----------|-------------|
| RLlib | `adapters/rllib/` | PPO/APPO training |
| Robomimic | `adapters/robomimic/` | Imitation learning datasets |
| Robosuite | `adapters/robosuite/` | Manipulation task environments |
| Input Devices | `devices/` | Xbox/Keyboard/Gamepad |
