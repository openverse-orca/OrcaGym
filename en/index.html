    🐋 Overview¶

    Welcome to the OrcaGym documentation!

    OrcaGym is an open-source robot simulation platform that provides an interface fully compatible with OpenAI Gym/Gymnasium, supporting multiple physics backends and distributed simulation.

    Quick Overview¶

    OrcaGym is a cloud-native robot simulation platform with the following core features:

    • :material-gym: Gymnasium Compatible — Seamless integration with existing RL algorithms
    • Multi-Physics Backend — Supports MuJoCo, PhysX, and ODE
    • Distributed Deployment — Supports local development and remote large-scale training
    • Ray Tracing Rendering — Realistic visual observations
    • Multi-Agent Support — Native heterogeneous agent management

    Who Should Use OrcaGym?¶

    • Reinforcement Learning Researchers — Need high-performance, standardized Gymnasium environments to train policies
    • Robotics Developers — Need workflows integrated with the OrcaStudio and OrcaLab platforms
    • Simulation Engineers — Need the flexibility of multiple physics backends and distributed deployment capabilities
    • Educators — Need an easy-to-use robot simulation teaching platform

    Companion Products¶

    OrcaGym is part of the robot simulation ecosystem:

    Product Description
    OrcaStudio Visual scene editing and simulation management tool
    OrcaLab Cloud-based robot training and evaluation platform
    OrcaGym (this repo) Python simulation interface library
